# Security

Do not disclose exploitable vulnerabilities, account data or credentials in public issues or pull requests.

Use [GitHub private vulnerability reporting](https://github.com/nixolas1/kvekk/security/advisories/new) if it is enabled. If that page is unavailable, open a public issue containing only “Please enable private vulnerability reporting”; include no vulnerability details. A maintainer can then arrange a private reporting route. Do not send secrets even in a vulnerability report.

For ordinary bugs, remove tokens, cookies, account identifiers, private URLs, local file paths and personal content from logs and screenshots before posting. Maintainers will never need your signing-in credentials.
