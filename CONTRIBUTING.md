# Contributing

Bug reports, feature requests, documentation fixes and source plugins are welcome. Search existing issues first. Keep proposals focused on the listener’s goal and include enough information to reproduce a problem.

## Public repository

Open a pull request for documentation or a declarative plugin. Plugins contain JSON data, never executable app code. Include a real, trimmed response fixture, truthful capabilities and evidence of permission to use the source. Run `python3 -I check_addon.py --strict` and report the result. A passing check does not prove that installation or live search works; report those separately.

Keep package and catalog versions in sync. Regenerate checksums after changes. Published package bytes are immutable: increase the package version before publishing a changed manifest. Contributors keep ownership of their work. By submitting material, you offer it under the applicable existing file license unless a different license is explicitly identified and accepted. Identify borrowed material, its source and its license. Do not submit content you cannot license.

## App improvements and private access

Use the core contributor application issue for a specific proposed improvement, your relevant experience and a public sample of your work if available. Do not post private contact details or credentials. A maintainer reviews the request and may agree a bounded contribution with you, then explicitly invite your GitHub account to the private app repository. Invitations and permission levels are chosen individually. Approval is not automatic and does not confer ownership, release privileges, signing-key access or unrestricted permissions.

Before private app work begins, agree its scope, access and contribution rights in writing. Existing PolyForm Noncommercial terms alone do not automatically grant the maintainer permission to incorporate someone else’s contribution into a paid proprietary edition. Any commercial grant or different contribution agreement must be explicit, voluntary and reviewed before that work is accepted. Do not assume a contributor application transfers copyright.

Private repository access can be withdrawn. Follow its development rules and keep source, credentials and private discussions out of this public repository. Release signing and publication remain maintainer responsibilities.
